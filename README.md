Token Radar ranks pre-token DeFi protocols by an implied token value derived from TVL, sector market-cap multiples, seven-day growth and tenure with no token, and gives each one a concrete farm plan. It reads a sealed DefiLlama snapshot and renders a sortable, filterable dashboard with a per-protocol detail view.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
